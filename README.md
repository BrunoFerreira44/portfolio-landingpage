# ☕ Bruno Ferreira — Portfólio

Portfólio profissional desenvolvido com **HTML, CSS e JavaScript puro**. Sem frameworks e com design responsivo.

---

## 📌 Seções

- **Início** — Apresentação com links para LinkedIn, GitHub e YouTube
- **Sobre Mim** — Resumo profissional com foto
- **Experiência** — Setores bancário e de telecomunicações
- **Habilidades** — Stacks técnicas que tenho experiência
- **Projetos** — Repositórios reais com links para o GitHub
- **Contato** — E-mail, localização e redes sociais

---

## 🗂️ Estrutura

```
PortfolioWeb/
├── css/
│   └── styles.css
├── js/
│   └── script.js
├── img/
│   └── Foto-Linkedin.jpg
└── index.html
```

---

## 🚀 Como rodar

Basta abrir o arquivo `index.html` no navegador. Não há dependências, build ou instalação necessária.
